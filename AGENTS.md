# Repository guide

## Agent skills

### Issue tracker

Local markdown issue files in `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo layout with a root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
