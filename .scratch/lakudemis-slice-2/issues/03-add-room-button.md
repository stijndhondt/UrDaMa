# 03: "+ Room" button in empty areas

**What to build:** Every enclosed area that has no Room shows a "+ Room" button inside it, whatever tool is active. Clicking it creates a Room there with the next default name, and selects it.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The button works with every tool active and does not start a drawing action.
- [ ] The new Room is selected, so it can be renamed straight away.
- [ ] All new UI text exists in English and Dutch.
